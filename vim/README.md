# vim

Instalador del componente `vim`, que instala **neovim**: `install.sh` es
`./install vim` y `uninstall.sh` es `./uninstall vim`. `paquetes` es la tabla
de lo que instala con apt/dnf (columnas: [`lib/paquetes.sh`](../lib/paquetes.sh)).

La config de neovim, lo que se edita, está en [`../nvim/`](../nvim/README.md).
